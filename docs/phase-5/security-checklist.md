## 2. Recurring

| When | Item |
|---|---|
| Every deploy | `check-site.mjs https://wiski.fun --origin-ip <ip>` all PASS; `docker compose ps` all healthy |
| Weekly | Dependabot PRs (npm, GitHub Actions, base images, infrastructure images) — merge when CI is green; read major updates |
| Weekly (automatic) | Cloudflare IP ranges refreshed (`systemctl list-timers wiskiflix-*`) |
| Nightly (automatic) | Backup + off-site copy; the worker verifies the audit hash chain at 03:30 and logs `alert=security` on a break |
| Monthly | Look at the backup log and R2 (`rclone ls wiskiflix-r2:wiskiflix-backups \| tail`); `df -h`; review moderator accounts (Admin › Pessoas) and remove access nobody uses |
| Quarterly | **Restore drill** (`restore.sh --drill`) and write the date below; rotate the GHCR read token |
| Yearly | Rotate `COOKIE_SEAL_KEY` (set the old one as `COOKIE_SEAL_KEY_PREVIOUS` for a day); renew nothing else unless exposed |
| On suspicion | Rotate the exposed secret, then revoke sessions (Admin › Pessoas), read the audit log (Admin › Auditoria) and check the backups. Side effects: `CSRF_SECRET` → open pages must reload; `COOKIE_SEAL_KEY` → sealed cookies (guest order links, overlays) must be renewed; `TOTP_ENCRYPTION_KEY` → moderators set the authenticator up again; database/Redis passwords → update `app.env`, `migrate.env` and the secret files together, then redeploy |

## 3. Accepted risks (reviewed 2026-10-31)

| Risk | Why accepted | Revisit |
|---|---|---|
| Firewall rules re-applied a few seconds after Docker starts at boot | nginx still refuses any TLS client without Cloudflare's origin-pull certificate in that window | if AOP is ever turned off |
| Cloudflare compresses HTML at the edge (BREACH-style length oracle on pages with the CSRF token) | the token is per session; exploiting it needs an attacker-controlled reflection in the same page and thousands of observed requests from the victim; nginx itself only compresses static assets | if a reflected-input page is ever added: a Cloudflare compression rule "off" for HTML |
| Trusted Types is report-only | Next.js's chunk loader still triggers it (P1-d) | Next.js release with a TT policy |
| Dev-only `minimatch` advisory | see L13 | ESLint 10 |
